# Module kotlinz

Functional programming library for Kotlin, providing higher-kinded type emulation,
type classes, and functional data types (under `com.github.kotlinz.kotlinz.data.*`).

# Package com.github.kotlinz.kotlinz

Core building blocks: higher-kinded type encoding (`K1`, `K2`, ...) and currying utilities.

# Package com.github.kotlinz.kotlinz.type

Type class hierarchy such as `Functor`, `Applicative`, `Monad`, `Category`, and `Arrow`.

# Package com.github.kotlinz.kotlinz.syntax

Monad comprehension (`fx`) syntax built on Kotlin coroutines.
